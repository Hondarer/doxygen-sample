# コーディング規範の確認

`app/general/docs/coding-guideline.md` の見出しから、変更する型、演算、異常入力、所有権などに該当する節を選んでください。  
対象パスの固有規範と合わせて、変更箇所と影響する呼び出し側を照合してください。  
検出コマンドを使う場合は対象 app に限定してください。

レビューでは指摘を裏付ける確認を選び、変更を伴う場合は影響範囲の局所ビルドまたはテストと、内容がある `.warn` を確認してください。  
すでに同じ変更で得た検証結果は再利用してください。  
Doxygen の契約や記法を変更する場合は `maintain-doxygen-comment` を参照してください。
