# コーディング規範の確認

1. `app/general/docs/coding-guideline.md` を読んでください。
2. 対象パスに適用される `AGENTS.md` と固有規範を確認してください。
3. 変更したシンボルと周辺コードを、該当する規範の節へ照合してください。
4. 規範にある検出コマンドは、対象 app に範囲を限定して実行してください。
5. 対象 app の局所ビルドとテストを実行してください。
6. 内容がある `.warn` ファイルを確認してください。

Doxygen コメントを変更する場合は `maintain-doxygen-comment` も使用してください。  
対象固有の規則は、一般規範を具体化する追加条件として扱ってください。  
一般規範を解除する規則は、解除する旨が `AGENTS.md` に明示されている場合にかぎり優先します。
