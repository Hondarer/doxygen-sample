# CI 警告の修正

`app/c-modernization-kit/docs/ci-warning-remediation.md` の対象アーティファクトと、警告種別の該当節を参照してください。  
ビルドまたはテストが失敗している場合は、失敗ログを先に調査してください。

対象 CI のビルド条件から原因と最小の修正範囲を特定し、変更内容と検証方法をユーザーへ報告して修正を進めてください。  
この進捗報告のために確認待ちで停止する必要はありません。  
許可された局所ビルドまたはテストで変更起因の失敗を修正し、対象の警告が解消するまで影響範囲を再検証してください。  
既存の無関係な警告や環境要因が残る場合は、原因と未確認事項を報告してください。  
警告ファイル自体は編集しないでください。
