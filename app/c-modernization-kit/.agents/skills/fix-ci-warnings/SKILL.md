# CI 警告の修正

1. `app/c-modernization-kit/docs/ci-warning-remediation.md` を読んでください。
2. 対象 CI の警告アーティファクトとビルド条件を確認してください。
3. 警告の原因と最小の修正範囲を特定してください。
4. 修正前に、変更内容と確認方法をユーザーへ示してください。
5. 最小範囲のビルドまたはテストを実行してください。
6. 内容がある `.warn` ファイルが残っていないことを確認してください。

ビルドまたはテストが失敗している場合は、このスキルではなく失敗ログを先に調査してください。  
警告ファイル自体は編集しないでください。
