# CI 警告の確認と修正

## 対象

この手順は、ビルドとテストが成功し、警告アーティファクトだけが残った場合に使用します。  
ビルドまたはテストが失敗している場合は、失敗ログを先に調査します。

## 確認対象

- `docs-warns.zip`
- `linux-ol8-warns.zip`
- `linux-ol9-warns.zip`
- `linux-ol10-warns.zip`
- `windows-warns.zip`

対象の CI 実行からアーティファクトを取得し、警告を発生元のファイルとオプションごとに分類します。

## 修正手順

1. 警告の発生箇所とビルド条件を確認します。
2. 同種の既存実装と正本規範を確認します。
3. 修正範囲と、必要な局所ビルドまたはテストをユーザーへ示します。
4. 警告の原因を修正します。
5. 最小範囲のビルドまたはテストを再実行します。
6. 内容がある `.warn` ファイルが残っていないことを確認します。

`.warn` ファイルや取得したログは直接修正しません。

## -Wpadded

構造体のパディング警告は、メンバー順、ABI、公開構造体かどうかを確認して判断します。  
公開 ABI を変える可能性があるため、警告抑制だけを目的にメンバーを並べ替えません。  
判断基準は [コーディング規範](../../general/docs/coding-guideline.md) の構造体パディングに関する節を参照してください。
